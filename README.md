# Pionero Funkin' · Descargas

Pagina de descargas de la ultima version del piloto, para Windows y Android.
Solo contiene el sitio y los paquetes publicados en Releases. El codigo del
mod y los archivos de trabajo no forman parte de este repositorio.

GitHub Pages publica `dist/`. `dist/latest.json` identifica la version visible
y sus enlaces. La pagina muestra solo la ultima entrega, sin historial.

Para actualizar: publicar los dos paquetes nuevos en una release y actualizar
latest.json, manteniendo los nombres de los assets y el enlace de esta pagina.
No guardar tokens ni claves de firma en el sitio.
